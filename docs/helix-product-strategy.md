# Helix Product Strategy

## User
AI power users, founders, design engineers, and agencies using Claude Code/Cursor/Codex/Hermes who need verified product/design execution.

## Job
Turn rough intent into professional, verified output without the user becoming a prompt engineer.

## Wedge
Best-in-class design reasoning, ethical design psychology, and prompt reprompting.

## Differentiator
Prompt packs provide specialists. Frameworks provide orchestration. Helix provides a portable execution OS with evidence, design reasoning, swarms, and self-improvement.

## Not doing
- giant undifferentiated persona dump
- unverified design claims
- dark-pattern conversion playbooks
- host lock-in
